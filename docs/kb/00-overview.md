# 00 · 产品全景与原则

## 一句话

**asin-lens** 是 ASIN 调研与变化记录工具：清楚、可追溯、可总结——用过去服务当下与未来。

## 业务主线

1. 项目管理 → 添加/导入 ASIN  
2. 采集 MCP（SellerSprite / Sif）→ **清洗 → 核对 → 入库**  
3. 快照 + 变化日志 → 趋势图  
4. 日报生成 → **核对 → 格式化** → 飞书/邮件  
5. 数据规则：源优先级、字段覆盖、报错清单  

## 非核心（点缀）

氛围主题、花语/欢迎语、自定义背景——可弱、不可抢业务。

## 架构四区

| 区 | 职责 |
|----|------|
| 前端 | 交互与呈现 |
| 后端 | 采集/清洗/报告/推送 |
| 基础设施 | DB、Cron、密钥、部署 |
| 交叉契约 | 类型与 API，改模块前必对齐 |
