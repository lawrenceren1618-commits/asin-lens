# 00 · 产品全景与原则

## 一句话

**asin-lens** 是以「我的产品」为中心的 ASIN 调研与优化工具：清楚、可追溯、可总结——用竞品行业报告服务自有 ASIN 的可优化项。

## 业务主线

1. 项目管理 → 添加/导入 ASIN（默认竞品；可选标记为我的，可多变体）  
2. 采集 MCP（SellerSprite / Sif，以 `docs/vendor` schema 为界）→ **清洗 → 核对 → 入库**  
3. 快照 + 变化日志 → 趋势图  
4. **异动日报**（Cron）与 **行业/优化报告**（按需）分离  
5. 数据规则：源优先级、字段覆盖、报错清单、词流量集中/分散判定  

## 非核心（点缀）

氛围主题、花语/欢迎语、自定义背景——可弱、不可抢业务。

## 架构四区

| 区 | 职责 |
|----|------|
| 前端 | 交互与呈现 |
| 后端 | 采集/清洗/报告/推送 |
| 基础设施 | DB、Cron、密钥、部署 |
| 交叉契约 | 类型与 API，改模块前必对齐 |
